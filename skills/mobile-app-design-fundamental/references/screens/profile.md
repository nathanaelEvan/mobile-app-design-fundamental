# Profile

**Job:** show a person (or account) and what you can do with them.

**Anatomy**
1. Avatar (64-96), name (headline-small), one line of context (body-medium, muted).
2. 2-3 facts in one quiet row (followers, joined, level), not tiles.
3. The primary action for this profile (Follow, Message, Edit profile), one filled button.
4. Content tabs only when there are 2-3 real collections; otherwise one list.

**Fails:** a giant cover photo pushing everything below the fold; stats as four coloured tiles;
both Edit and Settings buttons on your own profile when one is a row in the other.

**States:** your own vs someone else's; private or blocked; no content yet; long name and bio.
