# Home / dashboard

**Job:** show where things stand and the next action. Five-word test: "see today's progress".

**Anatomy (top to bottom)**
1. Top app bar: greeting or app name (title-large), one or two icon actions (profile, notifications).
2. Focal block: one hero metric or one status (display-small + body-medium context line), or the
   one card that matters today.
3. Next action: one filled button or a single prominent row ("Lanjutkan latihan").
4. Secondary: 2-3 metrics in a quiet row, then a short list (max 5 rows + "Lihat semua").
5. Navigation bar (3-5 destinations), with the bottom inset.

**Budget:** 1 hero, 1 primary action, ≤3 cards above the fold, ≤2 accented elements.

**Fails:** the 2×2 stat grid; a carousel of promos at the top; every section a card; a greeting
that takes a third of the screen; five equal-weight widgets.

**States:** first run (empty, with the one action that fills it), loading (skeleton in the
layout's shape), stale data (show it, mark the time, refresh quietly), error (inline banner,
keep cached content).
